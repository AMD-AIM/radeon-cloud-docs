每一步都是真实控制台的简短动图演示，容易遗漏的地方用橙色标出。第一次使用时按顺序看即可。

1. [登录](/radeon-cloud-docs/zh-cn/walkthroughs/sign-in/): 用 AMD 开发者计划账号登录，新用户先注册。
2. [查看积分](/radeon-cloud-docs/zh-cn/walkthroughs/credits/): 每张 GPU 每开始一小时扣 1 积分，直到实例删除。
3. [启动 Notebook](/radeon-cloud-docs/zh-cn/walkthroughs/launch/): 要保留文件，在「自定义」里选「持久化 /workspace」。
4. [在 JupyterLab 里工作](/radeon-cloud-docs/zh-cn/walkthroughs/jupyterlab/): 只有 `/workspace` 能保留。
5. [SSH 连接（可选）](/radeon-cloud-docs/zh-cn/walkthroughs/ssh/): 务必**先**加公钥再启动。
6. [销毁实例并保留成果](/radeon-cloud-docs/zh-cn/walkthroughs/keep-your-work/)：只有持久化的 `/workspace` 会保留。
7. [用 Token Factory 调用模型](/radeon-cloud-docs/zh-cn/walkthroughs/token-factory/): `max_tokens` 要留够，用 `/v1/usage` 查限额。

> 中国站：积分通过开发者积分兑换算力券获得。
