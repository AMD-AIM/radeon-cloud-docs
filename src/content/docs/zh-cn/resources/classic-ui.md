---
title: 经典版界面
description: 在经典版和新版控制台之间切换，以及经典版的各项功能在新版里的位置。
---

本文档以新版控制台为准。如果你的控制台里有 **Profile** 页面和 **My Templates**，说明你用的是经典版。

## 切换界面

- 在经典版里，点 **Switch to the new design**。
- 在新版里，点页头的 **经典版**；或者打开 **设置**，在 **界面** 下点 **使用经典版**。

浏览器会记住你的选择。

## 功能对照

| 经典版 | 新版 |
|---|---|
| **Profile → My Templates**，在模板上点 **Launch** | **首页** 的启动表单：直接选择镜像、规格和存储，不需要模板。 |
| **Profile → Active Instance** | **首页** 的实例卡片 |
| **Profile → SSH Public Keys** | **设置 → SSH 密钥** |
| **Profile → Credits Available → Redeem Credits** | **积分与用量** |
| **Profile → Model API Key** | **Token Factory**。**Regenerate Key** 暂时只在经典版里有。 |
| 模板的 **Deploy Type: vLLM Model API** | **首页 → 部署类型：模型 API** |
| **Gallery** | **模板库** |
| **Custom Images** | 仍在经典版里。构建完成的镜像会出现在新版启动表单的 **镜像** 列表中。 |

在经典版里创建的模板仍然保留在经典版中。新版 **首页** 启动实例不需要模板。
