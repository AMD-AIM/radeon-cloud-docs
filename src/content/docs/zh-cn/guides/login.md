打开 [radeon-global.anruicloud.com](https://radeon-global.anruicloud.com/)，点右上角的 **Login**，选择 **Login with Email**。

![AMD Radeon Cloud 登录界面](../../../../assets/guide/login.png)

填入邮箱和收到的验证码。验证码是六位数字，几分钟后失效；如果没收到，等冷却时间过了再重新发一次。

登录后点右上角头像，选 **Profile**。这个页面是你管理一切的地方：模板、正在运行的实例、SSH 公钥、API key 和额度余额。

![从头像菜单进入 Profile](../../../../assets/guide/click-profile.png)

## 如果账号还在审核

有些账号在能启动实例之前需要先通过审核。如果你看到相关提示，仍然可以浏览控制台、使用[免费的共享模型 API](/radeon-cloud-docs/zh-cn/guides/model-apis/) —— 审核通过后就能启动 GPU 实例了。
