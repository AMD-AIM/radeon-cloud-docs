title: 实例的组成
description: 实例由哪些部分组成：部署类型、镜像、规格、存储，以及如何计费。
---

实例是挂载了 AMD Radeon GPU 的容器。在控制台的 **首页** 启动，启动时选好运行什么、用多大规格。实例会一直运行，直到你销毁它，或者触发平台的限制。

## 启动时要选的内容

| 设置 | 决定什么 |
|---|---|
| **部署类型** | **Notebook** 提供 JupyterLab 和 SSH，用于开发；**模型 API** 用 vLLM 把模型部署成兼容 OpenAI 的接口，见[部署模型服务](/radeon-cloud-docs/zh-cn/guides/serve-model/)。 |
| **规格** | GPU 数量、CPU 核数、内存，以及每小时消耗的积分。 |
| **镜像** | 容器里的软件：ROCm、Python 和各类框架。见[选择镜像](/radeon-cloud-docs/zh-cn/guides/images/)。 |
| **资源池** | 实例调度到哪一组 GPU 节点上。启动表单会显示这个池此刻有没有空闲 GPU。 |
| **自动销毁** | 实例就绪后最长能运行多久。 |
| **工作区存储** | 实例销毁后，`/workspace` 是一起删掉，还是留下来下次接着用。见[保存数据](/radeon-cloud-docs/zh-cn/guides/storage/)。 |
| **挂载模型** | 以只读方式挂载的模型文件，大多数挂载在 `/models`。见[保存数据](/radeon-cloud-docs/zh-cn/guides/storage/#挂载的模型)。 |

表单默认显示 **部署类型**、**规格**、**镜像** 和 **自动销毁**。打开 **自定义** 才会显示其余选项。

## 账号能用哪些资源

表单里的规格、镜像和资源池都是分配给你账号的，其他账号看到的选项可能不同。出现在列表里只表示你可以申请，不代表已经为你预留了 GPU。

在终端里运行 `rcc catalog list` 可以看到同样的列表，见 [Radeon Cloud CLI](/radeon-cloud-docs/zh-cn/cli/instances/)。

## 每个账号同时只能有一个实例

实例运行期间，**首页** 显示的是这个实例，而不是启动表单。如果想再启动一台，需要先销毁当前这台。

## 计费

实例运行期间，每张 GPU 每小时消耗 1 积分。选规格时就能看到这一档每小时要花多少，例如 **1 GPU · 16 核 · 55GB · 1 积分 / 小时**。实例就绪后一两分钟内扣除第一个小时的积分。**首页** 的实例卡片会显示已运行时长和已消耗积分。

余额至少要够第一个小时；积分用完后，实例会被删除。见[积分](/radeon-cloud-docs/zh-cn/guides/credits/)。

## 实例会被自动停止的情况

- 积分用完，实例会被自动删除。
- 到了启动时选的 **自动销毁** 时间（从就绪起算），实例也会被删除，卡片上有倒计时。
- 临近销毁时可以点 **延长**，一次可以加 2 小时、8 小时或 1 天。每个实例只能延长一次，也不能超过启动时选的时长。

:::note
请把需要保留的结果存到持久化的 `/workspace`。实例被停止时，其他位置的文件都会丢失。
:::

## SSH 默认开启

从控制台启动的实例，SSH **默认开启**。偶尔会失败，例如下载 OpenSSH 没成功，或者 SSH 服务没起来。这时 JupyterLab 还能用，也可以自己进实例把 SSH 开起来。见[通过 SSH 连接](/radeon-cloud-docs/zh-cn/guides/ssh/)。

:::note
请在启动前到 **设置** 里添加公钥。
:::
