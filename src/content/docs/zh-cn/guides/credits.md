Radeon Cloud 用 **积分** 支付 GPU 实例的费用（英文界面叫 Credits）。共享模型 API 免费，不消耗积分。

积分和 AMD AI 开发者计划的 **开发者积分** 是两回事。开发者积分可以兑换成积分，见 [AMD AI 开发者计划](/radeon-cloud-docs/zh-cn/guides/developer-program/)。

## 积分怎么消耗

- 实例运行期间每小时消耗积分，消耗速度标在所选规格上，例如 **1 GPU · 16 核 · 55GB · 1 积分 / 小时**。
- 实例一启动就会扣除第一个小时的积分。
- 积分至少要够运行 1 小时才能启动。
- 积分用完时实例会被删除。在那之前请把工作保存到持久化的 `/workspace`，见[保存数据](/radeon-cloud-docs/zh-cn/guides/storage/)。
- 销毁后的实例不再消耗积分。用完请及时[销毁](/radeon-cloud-docs/zh-cn/guides/destroy/)，闲置的实例同样会消耗积分。

## 查看余额

点控制台右上角的账号，菜单里会显示余额，例如 **8,167 积分**。

要看详情，选 **积分与用量**。这个页面显示积分余额和模型 API 的用量情况。

`GET /api/me` 也会返回余额，见[账号](/radeon-cloud-docs/zh-cn/api/account/)。

## 获取积分

- **中国站**：用 AMD AI 开发者计划的开发者积分兑换优惠码。1 个开发者积分换 1 小时，每天最多换 20 个。见 [AMD AI 开发者计划](/radeon-cloud-docs/zh-cn/guides/developer-program/)。
- **活动**：黑客松和工作坊可能会直接发放优惠码。

## 兑换优惠码

1. 从账号菜单打开 **积分与用量**。
2. 点 **兑换积分**。
3. 在弹出的 **兑换积分** 对话框里粘贴完整的优惠码，点 **兑换**。

输入框里的示例是 `RDN-XXXX-XXXX-XXXX`，但开发者计划发的优惠码是一长串字母、数字和符号，请完整粘贴。

兑换成功后，控制台会提示加了多少积分，余额立即更新。如果提示 **代码无效，请检查后重试。**，说明优惠码不完整、已过期、已经用过，或者属于另一个站点。见[兑换失败怎么办](/radeon-cloud-docs/zh-cn/guides/developer-program/#兑换失败怎么办)。

积分只属于兑换它的站点，不能在中国站和全球站之间转移。

## 模型 API 用量

共享模型 API 不消耗积分。它有自己的每日用量上限，以 pts 计量，每天北京时间 0 点（UTC+8）重置。

**积分与用量** 页面显示：

- **每日模型上限**：今天已经用了多少、什么时候重置。
- **按模型**：每个模型的请求数和用量。
- **最近请求**：最近 24 小时的请求，按你所在时区显示。

也可以用 API Key 调用 [`GET /v1/usage`](/radeon-cloud-docs/zh-cn/api/usage/) 读取同样的数据。
