本条款适用于 **Model API**，即本章节文档所描述的免费共享端点。它不约束 GPU 实例、
模板以及平台的其他部分。

Model API 由 AMD 开发者社区提供，是面向 AMD 硬件用户与开发者的**试用与开发服务**。
它完全免费，按现状提供。

申请 API Key 并调用这些端点，即表示你接受以下条款。

## 用途

试用模型、做原型验证，判断 AMD 加速卡是否适合你的工作。典型场景包括评估、实验、
学习、演示、黑客松和开源开发。

## 不要用于生产

**不要把生产负载架在这些端点上。** 没有服务等级协议、没有可用性承诺、没有支持义务。

具体而言：

- 目录里的模型可能在很短通知甚至无通知的情况下新增、变更或下线。
- 端点和 API Key 可能因运维原因被重启或吊销。
- 容量是共享的。服务繁忙时请求可能被限流或拒绝。
- 这里的一切都不为高可用设计。

如果你的业务依赖端点不中断，请放到有商业协议保障的地方。

## 模型是上游原版

模型使用其**公开发布的上游权重**，未经修改，运行在 AMD 加速卡上。我们不做微调、
不做蒸馏，也不会拿另一个模型顶着别人的名字提供服务。

由此有两点：

- 模型的行为、能力和限制就是上游模型本身的。请阅读它的模型卡，其许可证同样适用于
  你对输出结果的使用。
- 我们不保证任何输出是准确、安全、最新或适用于特定用途的。你要依赖的内容请自行
  复核。

响应里报出的模型名就是实际产出它的模型。**如果你是通过第三方接入本服务、而对方告
诉你这是另一家厂商的模型，那么你被误导了**——见[禁止转售](#禁止转售)。

## 完全免费

Model API 免费。额度、配额和速率限制是容量控制手段，不是货币，不具有任何金钱价值。
免费也意味着你并未购买任何权益：配额可能调整，访问可能被暂停，且不作补偿。

## Key 与账号

一人一个 API Key。用你的 Key 做的一切由你负责，请妥善保管，泄露后及时轮换。

以下行为会导致 Key 被停用：

- 同一个人在多个账号上持有 Key，**包括使用邮箱地址中的点号、`+` 标签等别名手法**。
- 分享、转让或出售 API Key。
- 用脚本批量注册账号以获取更多 Key。

## 禁止转售

**不得转售、再许可，或以任何方式把这些端点的访问权提供给他人，无论是否收费。** 包括：

- 把 API 直接或通过代理、网关、聚合平台暴露给第三方。
- 把本服务或其模型包装成你自己的产品，或冒充另一家厂商的产品。
- 通过提示词指示模型谎报自己是哪个模型、由哪家提供。
- 汇集多个账号或 Key，为一个群体放大可用容量。

任何人都可以在 [Token Factory](https://developer.amd.com.cn/radeon/modelapis)
免费注册、直接使用这些端点。**没有理由为访问它向任何第三方付费，我们也没有授权任何
第三方销售它。**

被认定为转售的 Key 会被停用。使用已停用 Key 的调用会收到一条说明原因的提示，
以便通过转售商获得访问的人知道发生了什么，并直接注册。

## 可接受使用

不得使用 Model API：

- 违法，或侵犯他人权利。
- 生成恶意软件、漏洞利用代码，或用于未授权侵入系统的工具。
- 攻击、探测或压垮任何系统，**包括本平台**——测试你自己的系统可以，测试别人的
  不行。
- 绕过配额、速率限制、鉴权或内容安全机制。
- 生成涉及未成年人的性内容，或骚扰、诽谤、煽动针对特定人群暴力的内容。
- 冒充个人或组织，或生成声称由其撰写的内容。
- 处理个人信息、健康、金融等敏感数据。**这是试用服务，不要向它发送任何机密内容。**

## 我们记录什么

我们会记录 API 请求，**包括提示词与模型输出的内容**，以及时间、模型、token 数、
错误等元数据。

- **对话内容只保留很短的滚动窗口**——当前为两天——之后删除。元数据保留更久，用于
  用量核算。
- 内容**仅**用于运营服务：容量规划、故障排查、滥用检测，以及本条款的执行。
- **我们不用你的数据训练模型**，也不出售，不提供给第三方作其自身用途。

在需要调查具体滥用事件或履行法律义务时，相关内容可能保留超过上述窗口。

我们把这件事直说，是因为它是事实，而不是因为它听起来舒服：**如果一段内容你不希望
被存下来，就不要发过来。**

## 停用

违反本条款的 Key 可能被停用，且不另行通知。在合理怀疑存在滥用且仍在调查期间，
我们也可能先行停用。

如果你认为 Key 被误停，请联系
[member-service@mail.developer.amd.com.cn](mailto:member-service@mail.developer.amd.com.cn)。

## 变更

我们可能随时变更、暂停或终止 Model API 的任何部分，也可能修订本条款。重大变更会在
本页更新并标注新日期。变更后继续调用即视为接受。

## 免责

Model API 按**现状**和**可用状态**提供，不附带任何形式的保证。在法律允许的范围内，
我们不对你使用本服务产生的任何损失负责，包括数据丢失、利润损失，或依据模型输出
行事所导致的后果。
